# 🚚 QuickShip - Smart Courier & Logistics Management System

QuickShip is a full-stack Smart Courier & Logistics Management System built using Spring Boot and Java. It provides secure shipment management, courier assignment, package tracking, and role-based access control for customers, couriers, and administrators.

---

## 📌 Project Overview

QuickShip is designed to simplify courier and logistics operations by providing a centralized platform where customers can book shipments, couriers can manage deliveries, and administrators can monitor the entire logistics process.

---

## ✨ Features

- User Registration & Login
- JWT Authentication
- Role-Based Authorization
- Shipment Booking
- Shipment Tracking
- Courier Assignment
- Delivery Status Updates
- Customer Dashboard
- Courier Dashboard
- Admin Dashboard
- REST APIs
- Input Validation
- Global Exception Handling
